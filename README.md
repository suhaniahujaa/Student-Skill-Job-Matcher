# Student Skill & Job Matcher

## About the Project

This is a Java project that helps students find suitable jobs based on their skills.

The program compares the student's skills with the skills required for different jobs and shows the match percentage.

## Features

- Enter student name
- Enter email
- Select skills
- Find suitable jobs
- Calculate match percentage
- Show the best job
- Suggest skills to learn

## Jobs Included

- Data Analyst
- Java Developer
- Machine Learning Intern
- Web Developer

## Technologies Used

- Java
- Java Swing
- IntelliJ IDEA

## How It Works

1. Enter your name and email.
2. Select your skills.
3. Click "FIND JOBS".
4. The program checks your skills.
5. It calculates the match percentage.
6. It shows the best job for you.
